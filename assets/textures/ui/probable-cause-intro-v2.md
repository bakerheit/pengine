# Probable Cause intro v2

The title remains exactly **Probable Cause**, using the bundled OFL Righteous
font. The logo is a separate transparent layer, reproducible with
`tools/make_probable_cause_intro_logo.py`. Navigation uses existing Bebas Neue.
The previous v1 artwork is retained.

The background was made with the built-in image generation tool. Final prompt:

> Use case: stylized-concept. Asset type: text-free widescreen 16:9 background plate for the main menu of Probable Cause, a 1991 urban crime game with AAA PlayStation 2 roots. Scene: rainy industrial waterfront street at night in a fictional American island city. A boxy dark burgundy late-1980s sedan parked in three-quarter rear view occupies the RIGHT half, entirely inside the right two-thirds with breathing room. Warehouse brickwork, telephone poles, distant docks, sodium amber street lamps and wet asphalt with a faint distant red police-light reflection. Composition: eye level cinematic wide shot, LEFT 45 percent very dark quiet negative space for a separate logo and vertical menu; enough detail on the right to tell a story. Style: sophisticated hand-painted game key art, visible broad brush shapes and simplified PS2-era geometry, not photorealistic, not cartoon outlines, no modern car. Restrained asphalt charcoal, bone highlights, amber streetlight and muted burgundy; atmospheric fog. Subtle grounded crime-drama mood. Edge-to-edge environment, no frame. No people, NO TEXT anywhere, no lettering, no logos, no menu, no interface, no loading bar, no watermark. Do not put Probable Cause or After Dark in the image.

## Runtime layers

- Aspect-correct cover crop; 1.5% overscan allows very slow horizontal drift.
- Low-contrast procedural rain, composed beneath the stable Righteous logo.
- Live startup stage labels; no baked loading bar or made-up percentages.
- Seven-second minimum, followed by menu fade-in on the same scene.
- Existing Start Game / City Map / Quit actions and shared pointer layout.
- Original 16-second synth score and rain stems generated by
  `tools/make_probable_cause_intro_audio.py`; no third-party samples. Music and
  rain use their own mixer categories and fade out when gameplay starts.

Startup redraws between synchronous initialization stages. A single heavy
stage can still pause animation until that stage returns; this is not a
background-thread loader. No police speech, flashing lights or extra subtitle.

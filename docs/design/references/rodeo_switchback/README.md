# 1991 Rodeo Switchback references

Selected from [candidate 2](concept-selected.png): a short-wheelbase, two-door
4x4, separate from Rodeo's Grazer pickup. These seven images are the modeling
reference set. All images depict the same burnt-orange lower body, cream
removable rear hardtop, black bumper and arch cladding, steel wheels, and
tailgate spare.

| Feature | Controlling views |
|---|---|
| Overall identity and material boundaries | [front three-quarter](front-three-quarter.png), [rear three-quarter](rear-three-quarter.png) |
| Wheelbase, doors, roofline and overhangs | [left](left.png), [right](right.png) |
| Grille, lamps, bumper width | [front](front.png) |
| Tail lamps, swing door and spare tire | [rear](rear.png) |
| Hood and solid orange/cream roof panels | [top](top.png) |

Resolve image differences by keeping **one side door per side**, one large
window in each side of the cream hardtop, and a solid cream roof with no roof
glass. The spare hangs on the single rear swing door. Let the side views set
axle positions; the three-quarter views are for surface and material shape.
Dimensions remain estimates until the modeling shape contract is written.

The runtime model uses transparent glass and mapped cabin and door-back
surfaces. This reference set is concept art, not a recovered engineering
drawing. Rebuild the playable model with
`python3 tools/make_1991_candidates_assets.py rodeo_switchback`.

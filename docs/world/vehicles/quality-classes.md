# Vehicle quality classes

[Vehicle directory](README.md) · [World](../README.md)

Quality classes describe the maturity of a vehicle's design, model detail, documentation and reference imagery. **Pizaz Constant, Rodeo Switchback and Harrow Hookline are user-designated Class 3 benchmarks.** Use their model pages and galleries to guide upgrades: [Constant](Pizaz/Constant.md), [Switchback](Rodeo/Switchback.md) and [Hookline](Harrow/Hookline.md).

## Working class definitions

| Class | Design and detail standard |
|---|---|
| Class 1 | Basic vehicle form and identity; substantial refinement and supporting documentation are still needed. |
| Class 2 | Developed design with useful detail, but remaining modeling, surface, interior or documentation gaps keep it below the benchmark. |
| Class 3 | Well designed and detailed, with good model documentation and reference images. Pizaz Constant, Rodeo Switchback and Harrow Hookline establish the target standard. |

Class 1 and Class 2 are working descriptions for future reviews. Other vehicles remain unclassified until individually reviewed. Record an assigned class on the model page with the reasons and evidence for it.

Class describes visual and documentation quality. Track playable integration, build status and runtime verification separately.

## Bring a vehicle up to Class 3

1. **Compare the evidence.** Open the target vehicle's concept and available angle views alongside Constant's [references](Pizaz/Constant.md#reference-photos) and [model renders](Pizaz/Constant.md#model-angles), or Switchback's [references](Rodeo/Switchback.md#reference-photos) and [playable model views](Rodeo/Switchback.md#current-playable-model). For a recovery truck, use Hookline's [references](Harrow/Hookline.md#reference-photos) and [playable model views](Harrow/Hookline.md#current-playable-model). Choose the benchmark most useful for the target's body style. Identify specific gaps in shape, detail, materials, interior and documentation.
2. **Refine the vehicle's own design.** Preserve its manufacturer identity, era, body style and intended role. Use the Class 3 benchmarks’ level of care to guide believable proportions, body curvature, fitted panels and consistent details across views.
3. **Finish visible surfaces.** Refine panel seams, lamps, grille, trim, mirrors, wheels and tires. Transparent windows should reveal a finished cabin. Doors and other visible modules need finished inner faces wherever a camera or open door exposes them.
4. **Complete the model page.** Keep the selected concept directly under the title. Save and embed available front, rear, side, top and three-quarter references, followed by clearly labeled model renders and useful interior or door views. Record model information, construction notes, source paths and any remaining gaps.
5. **Review the result.** Compare matching angles against the vehicle's own references and the Class 3 benchmarks’ quality level. For changes to a playable model, validate its cooked game appearance and affected features. Record what improved, what was checked and any unresolved issues before recording the new class.

Reference galleries should state their actual coverage. Constant currently has a selected three-quarter concept plus front, rear, one side and top references; it also has seven model and door renders. Its Class 3 designation stands as assigned by the user. Future reference generation continues to follow the vehicle workflow's full directional set requirement.

Switchback and Hookline each include a selected concept, seven directional references, playable model captures and door/interior views.

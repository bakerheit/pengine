# Karlsdale

[Vehicle directory](README.md) · [World](../README.md)

Formal early-motoring luxury, from pre-war sedan to stretch limousine.

Karlsdale is the current working name for the period luxury range: Lux, Regent Eight and Six Sedan. Historic Halcyon and Montrose asset identifiers are retained. Founding details and a fitted manufacturer badge have not been established.

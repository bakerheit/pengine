# Monthly Mint billboard

`assets/textures/world/billboards/monthly-mint.png` is an original generated
fictional toothpaste ad. The finished image is 1280 x 588 pixels (1280:588,
about 2.177:1) and maps once across the existing 12 x 5.5125 m billboard face.
It uses the copy “MONTHLY MINT” and “BRUSH ONCE A MONTH!” in a playful
mid-century print-ad style.

The board stands at the existing roadside billboard site at world origin
(25.2943, -73.8585), on the block south of Halloway Street. It faces traffic
on that arterial. The separate Pinnaty Taxi billboard is unchanged.

# Loom Museum interior textures

Runtime assets in `assets/textures/world/loom_museum/`, all generated by
[`tools/make_loom_museum_textures.py`](../../tools/make_loom_museum_textures.py).
Re-running the script reproduces them: every value is drawn from fixed geometry
or one fixed-seed LCG, and text uses system fonts by absolute path. Diffuse
albedo only — the renderer supplies the lighting, and a baked highlight in a
wall sheet fights the gallery fixtures that are meant to be doing the work.

The painting atlas is a separate, image-generated asset; its provenance is in
[`loom-museum-art.md`](loom-museum-art.md).

| File | Size | Use |
| --- | --- | --- |
| `gallery-plaster.png` | 256² | Wall lining in all eight galleries and the hall |
| `gallery-parquet.png` | 256² | Square-basketweave oak floor in the galleries |
| `coffer-ceiling.png` | 256² | Coffered soffit, one coffer per 4 m tile |
| `gallery-plaques.png` | 1024 × 256 | 4 × 2 atlas: the eight portal plaques |
| `gallery-panels.png` | 2048 × 1024 | 4 × 2 atlas: one large wall graphic per gallery |
| `exhibit-labels.png` | 1024 × 1024 | 4 × 8 atlas: 24 object labels, 8 cells spare |
| `museum-directory.png` | 512 × 768 | The lobby directory board |

## Why these are near-neutral

`gallery-plaster.png` is almost white and the parquet and coffer sheets are
close to grey. Colour comes from a per-room tint in `src/app/world.cpp`, which
is how one 256px sheet dresses eight galleries in eight different colours. The
tints are pitched against a cool interior ambient: anything already blue-grey
in the table lands as navy in game, and anything dark lands as black. Only the
art room's burgundy is meant to read dark.

## Atlas cell order

Cells run left to right, top to bottom, and the plaque and panel sheets share
the gallery order in `loom_room()`: ART, ANTIQUITIES, NATURAL HISTORY, PINATTY
HISTORY, SCIENCE, SPACE, TRANSPORT, DESIGN. The sim side names a cell by index
(`museum panel 3`, `museum label 07`) and never learns that a sheet exists;
`museum_atlas_cell()` in the host layer maps the name to a quadrant.

Texture upload flips vertically, so v counts **down** from 1: sheet row 0 is
the v range nearest 1. Getting that backwards does not fail loudly — every room
quietly shows another room's graphic — so `add_atlas_cell_quads()` follows the
painting quads, which are the reference for the convention.

`tests/loom_cultural_tests.cpp` asserts that all 24 label cells are placed
somewhere. An unused cell means a label was dropped from a room without anyone
noticing.

## Fitting

Titles and subtitles are shrunk until they fit their cell. A cell that
overflows bleeds into its atlas neighbour, which shows up in game as a letter
from the next room's sign, so the fit is measured rather than eyeballed per
string.

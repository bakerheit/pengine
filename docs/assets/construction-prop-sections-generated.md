# Fitted construction prop sections

Generated 2026-09-05 with the built-in `image_gen` tool through the imagegen
skill. These are non-seamless, single-section RGB materials. The renderer maps
each one once across its matching authored `StartPart`, instead of using the
generic world tile scale.

## Prompt set

All prompts used the same base constraints: `Use case: stylized-concept`,
low-resolution PSX-era game texture, opaque RGB albedo, non-seamless fitted
section texture, no watermark, no logos, no readable text, no perspective, no
3D geometry, and avoid seamless tile/pattern wallpaper/repeated motifs.

- `fence-section-generated.png`: one wide continuous orange safety-mesh fence
  panel with sparse support seams, uneven fabric, and restrained grime.
- `crane-section-generated.png`: one tall crane steel section with worn
  safety-yellow paint, sparse bolts, rust seams, and one restrained hazard edge.
- `rebar-section-generated.png`: one bundled rebar/steel-stack face with rods,
  tie wires, chalk marks, rust, and dusty handling grime.
- `depot-facade-section-generated.png`: one wide galvanized corrugated depot
  facade with three to five irregular panel bays, rust drips, and dust.
- `equipment-body-section-generated.png`: one compact-equipment body panel with
  chipped yellow paint, exposed steel, grease, and large scratches.
- `barrier-face-section-generated.png`: one Jersey barrier face with one broad
  faded yellow stripe and continuous concrete wear.
- `wayfinding-board-section-generated.png`: one plywood board face with broad
  faded blue paint, a red edge block, wood grain, nails, and grime.
